# The native shell

The App Store / Google Play build of BPM. A Capacitor 8 WebView that loads the
**live** site (`capacitor.config.ts` → `server.url`), so there is no native
build of the web app: a web deploy is already a native update, and the shell
is archived a few times a year. Intent and decisions: `docs/plans/native-shell.md`.
Runtime detection in the web app: `lib/native.ts`. Store-side requirements
(labels, Data safety, review notes): the approved plan in Grant's plans folder.

## What is in git

| Path | What | Generated by |
|---|---|---|
| `capacitor.config.ts` | the one config | hand-written |
| `native/www/` | `index.html` (never shown) and `error.html` (the offline page) | hand-written |
| `native/assets/` | 1024 icon, adaptive fg/bg, 2732 splash | `node scripts/gen-icons.mjs` |
| `ios/`, `android/` | the projects, icon sets, splash sets | `cap add`, `@capacitor/assets`, then hand edits below |

Never in git: `ios/App/App/GoogleService-Info.plist`, `android/app/google-services.json`
(bundle-restricted, but per-project — drop them in locally), keystores, `.p8`,
provisioning profiles, build output (`.gitignore`).

Hand edits on top of the templates — re-apply if a template is ever regenerated:
`ios/App/App/Info.plist` (scheme `bpm`, portrait, `ITSAppUsesNonExemptEncryption`,
`remote-notification`), `App.entitlements`, `PrivacyInfo.xcprivacy`,
`AppDelegate.swift` (Firebase configure + APNs forwarding), `project.pbxproj`
(`CODE_SIGN_ENTITLEMENTS`, `TARGETED_DEVICE_FAMILY = 1`, `MARKETING_VERSION`),
`AndroidManifest.xml` (scheme, App Link, channel, `POST_NOTIFICATIONS`,
no cleartext), `MainActivity.java` (notification channel), `strings.xml`.

## Toolchain (this Mac, 2026-09-03)

- Xcode.app is installed but the CLI points at Command Line Tools:
  `sudo xcode-select -s /Applications/Xcode.app/Contents/Developer`
- iOS uses **SPM**, not CocoaPods — nothing to install.
- Android: install **Android Studio** (bundles JDK 21 and the SDK; Capacitor 8
  needs JDK 21). No Java or SDK is on this machine yet.

## One-time setup

1. **Firebase project** (push on both platforms). Add an iOS app
   (`com.grantzou.bpm`) → download `GoogleService-Info.plist` →
   `ios/App/App/`, then in Xcode add it to the App target. Add an Android app →
   `google-services.json` → `android/app/` (Gradle applies the plugin only when
   the file exists). Upload the **APNs auth key (.p8)** from the Apple developer
   account under Cloud Messaging → Apple app configuration. Create a service
   account key → Azure App Setting `FCM_SERVICE_ACCOUNT_JSON` (one line).
2. **Xcode** (`npm run native:ios`): set the Team; Signing & Capabilities →
   the entitlements file is already wired (Push Notifications, Associated
   Domains). Drag `PrivacyInfo.xcprivacy` into the App group with target
   membership App.
3. **Android Studio** (`npm run native:android`): generate an **upload
   keystore** (keep it out of git); Play Console → App integrity → copy the
   **App Signing** SHA-256 into the Azure App Setting `ANDROID_ASSET_LINKS`.
   The upload key's fingerprint is the wrong one — App Links then silently
   never verify.
4. **AASA**: Azure App Setting `APPLE_APP_SITE_ASSOCIATION` with the Team ID.
   `curl -sI https://bpm.grantzou.com/.well-known/apple-app-site-association`
   must be 200 `application/json` with no `location`.

## Build

```
npm run native:assets   # only when the mark or splash changes
npm run native:sync     # copies native/www + plugin config into both projects
npm run native:ios      # Xcode → Product → Archive → TestFlight
npm run native:android  # Android Studio → Build → Generate Signed Bundle (AAB)
```

Version: `MARKETING_VERSION` / `versionName` are the store version (1.0.0);
bump `CURRENT_PROJECT_VERSION` / `versionCode` on every upload.
